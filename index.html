open a project

Pick a folder that has a project.json in it, or an empty one to start a project there. Everything the app writes goes into it: scenes, saved brains, and the checkpoints and metrics of every run.

    new project

    A folder of its own, made inside the location, with the guided tour as its first scene.

    open a scene

      add a node module

      A node module is a JavaScript file that adds nodes to the Tab menu. It runs in this page with the same access as the app: add code you wrote or trust. The file is copied into the project's nodes folder and loads with the project from then on.

      start a training run

      This runs the graph on screen for the hours set on the checkpoint, writing metrics and brain files on its own cadence. It drives this page, so the graph, the properties panel and neuron inspection stay live and describe the network that is training. The settings are on the checkpoint node.
