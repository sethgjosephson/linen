printed. One file per release; a reader checks a claim against the
record rather than against the sentence that makes it.

from the release's `cuda/engine.cu` (`nvcc -O3 -arch=sm_89`), run
2026-11-10 on Windows 11 with an sm_89 NVIDIA GPU, the Brian 2
checks in a Python environment with Brian 2 and Elephant.
